# 生成眼神跟随举牌交互的网页

在examples/hold_sign/下，以参考图搭建 16:9 工作室官网 Hero，人物举牌视频作为背景，保留两侧简洁排版。鼠标上下移动时，按移动距离控制视频前进或倒退，停止后停在当前画面，不自动播放。先从视频关键帧标定玻璃卡片的位置，再用平滑曲线计算完整轨迹；将头像、文字、数据和按钮作为网页元素叠加到空白玻璃卡片上，随实际显示的视频帧同步移动。适配不同屏幕比例，确保内容始终贴合卡片。

核心实现原理(Architecture & Mathematics)，该交互涉及 4大工程核心，缺一不可：

1. Catmull-Rom 样条曲线插值（getCardTop(seconds)）:
●传统线性插值(lerp）在人物手臂起伏加速、减速时会出现抖动或脱节。
●本方案在视频每秒(0s, 1s, 2s,3s, 4s, 5s)标定一个物理基准百分比位置，使用四点 Catmull-Rom 样条实时计算平滑的位置连续性($C^1$ 连续)，确保卡片在任意播放时间点绝对
平滑吸附。
2. 鼠标垂直位移微分与无缝阻尼(Mouse Delta Scrubbing)：
·不采用将页面直接划分为绝对区域的粗暴映射，而是监听鼠标相对运动偏移量deltaY。
●通过requestAnimationFrame聚合并施加灵敏度系数，计算targetTime，让交互如同旋转调音旋钮一样细腻。
3.物理帧级双通道渲染（requestVideoFrameCallback+onSeeked):
●利用现代浏览器原生requestVideoFrameCallback，当视频解码出真实新帧时立刻同步 CSS 变量-card-y。
●在支持fastSeek()的浏览器（如 Safari/Chrome）优先调用以保证 60fps+的超高响应率；在静止时通过精确 seek 校准最终静止帧。
4. 自适应容器查询 (CSS Container Queries:cqw/cqh）:
●Ul 舞台使用container-type:size，使卡片的位置与尺寸完全绑定在视频的虚拟视口网格上，无论在 16:9 桌面宽屏还是异形屏幕上均绝无错位。
